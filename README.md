## EvenTicket — Controle de Eventos

## 1. Sobre o projeto

O EvenTicket é um projeto de sistema de controle de eventos, participantes e inscrições.

O sistema tem como objetivo organizar os eventos, controlar os participantes inscritos e gerenciar as inscrições de acordo com a capacidade disponível em cada evento.

O projeto será desenvolvido por meio da elaboração do modelo conceitual e do modelo lógico do banco de dados, considerando as regras de negócio e os requisitos estabelecidos para o cenário.

## 2. Regras gerais do sistema

- Um participante pode se inscrever em vários eventos.
- Um evento pode possuir vários participantes inscritos.
- A inscrição estabelece a relação entre participante e evento.
- Um participante não pode realizar duas inscrições para o mesmo evento.
- Uma inscrição só pode ser aceita quando houver vagas disponíveis.
- O cancelamento de uma inscrição deve liberar a vaga correspondente.
